# Deepwork

**Full focus mode for Windows and macOS.** Таймер и 4 уровня строгости, отключение уведомлений, блокировка сайтов и программ, чистка Brave от отвлечений, лимиты сайтов, план с рутинами, журнал с разбором недели, Telegram-бот и приложение для телефона.

![Фокус](docs/focus.png)

## Что умеет

**Фокус-сессии**
- Помодоро, обычный таймер или Поток (работаешь сколько идёт, перерыв = 1/5 отработанного).
- **Шаблоны**: «Код 90 · Жёсткий · набор Код» в один клик — на экране «Фокус», в трее, по `Ctrl+Alt+F` и с телефона.
- **Рабочие наборы**: программы и сайты, которые открываются при старте. Программы из набора блокировка не закрывает.
- **Парковка мыслей**: `Ctrl+Alt+Space` в любой программе → поле поверх всех окон → мысль уходит в бэклог, а ты остаёшься в фокусе.
- **Фоновые звуки**: коричневый и розовый шум, дождь, прибой, бинауральный ритм. Генерируются самим Deepwork, без файлов.
- **Экран перерыва** во весь экран с дыхательным кругом и подсказками; мягкий (можно пропустить) или строгий.
- **Дзен-режим**: во время сессии на экране только кольцо таймера.
- **Таймер на рабочем столе** и собственные уведомления: начало перерыва, минута до конца, конец перерыва, конец сессии.
- **Простой не считается**: отошёл больше чем на 5 минут — это время не попадёт в фокус.

![Сессия](docs/running.png) ![Виджет](docs/widget.png)

**4 уровня фокуса** (любой пункт меняется в «Настройках»)

| | Лёгкий | Рабочий | Жёсткий | Монах |
|---|---|---|---|---|
| «Не беспокоить» | ✓ | ✓ | ✓ | ✓ |
| Сайты | предупреждение | блок | блок | только белый список |
| Блок в hosts (все браузеры) | | | ✓ | ✓ |
| Программы | | закрывать из списка | закрывать из списка | только белый список |
| Закрывать другие браузеры | | | ✓ | ✓ |
| Разблокировка в перерыв | ✓ | ✓ | | |
| Перезапуск, если Deepwork убили | | | ✓ | ✓ |
| Досрочный выход | в любой момент | ввести фразу | фраза и 60 с | аварийный, 5 мин |

На уровнях «Жёсткий» и «Монах» отдельный сторожевой процесс поднимает Deepwork обратно, если его закрыли через диспетчер задач, а Brave с выключенным расширением закрывается.

**Brave**
- При старте фокуса закрывает отвлекающие вкладки (или все, кроме рабочих) и возвращает их после сессии.
- Блокирует сайты страницей с таймером и целью сессии; попытки зайти попадают в статистику.
- **Лимиты сайтов**: например, YouTube 30 минут в день — всегда, не только в фокусе. Лимит кончился — сайт закрыт до полуночи.
- Считает время на сайтах за день.
- YouTube без Shorts, рекомендаций, заставок, комментариев и автозапуска; кликбейт размывается; ленты соцсетей скрыты; push-уведомления сайтов запрещены.

![Блокировка](docs/blocked.png)

**План**
- Календарь на месяц: задачи, полоска фокуса за день, события из Google Календаря (по ICS-ссылке).
- **Утренний ритуал**: при первом открытии за день — выбрать до трёх главных дел; они весь день наверху.
- **Сессии по расписанию**: напоминание за 2 минуты, старт с вопросом, сам или «контракт».
- Рутины по дням недели, бэклог, цели с прогрессом. Быстрый ввод: `14:30 созвон !1 50м`.

![План](docs/plan.png)

**Журнал**
- День: настроение, энергия, что получилось, что мешало, план на завтра (одной кнопкой → задачи), заметки после сессий и автоматический итог: фокус, качество, простой, сайты, парковка.
- Неделя: цифры против нормы, таблица по дням, выводы по данным и разбор «что сработало / что убрать / фокус на неделю».
- **Вечерний итог**: в заданное время журнал открывается сам.

![Журнал](docs/journal-week.png)

**Статистика**
- Тепловая карта за полгода, 14 дней против нормы, серии (выходные по норме = 0 серию не прерывают).
- **Лучшее время**: фокус по часам и дням недели и твоё лучшее двухчасовое окно.
- **Качество фокуса**: сколько времени во время сессий было в рабочих программах.
- Точность оценок задач, время по целям, время на сайтах, что тянет отвлечься, 16 достижений.

![Статистика](docs/stats.png)

**Вне компьютера**
- **Telegram-бот** (свой, через @BotFather): `/status`, `/today`, `/plan`, `/focus 50`, `/park мысль`, `/add задача`, итог дня вечером. Выйти из фокуса через бота нельзя.
- **Телефон**: веб-приложение в той же Wi-Fi сети — таймер, старт фокуса, задачи, рутина, журнал, парковка. На iPhone и Android добавляется на главный экран.

**Ещё**
- Мастер первого запуска, палитра команд `Ctrl+K`, горячие клавиши в любой программе.
- Ежедневные резервные копии, экспорт и импорт, перенос данных в OneDrive/iCloud для двух компьютеров.
- Проверка обновлений и обновление в один клик.

## Установка

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
git clone https://github.com/pravorov333-pixel/deepwork
cd deepwork
npm install
npm start
```

При первом запуске откроется мастер настройки. Ярлык на рабочем столе и в «Пуске» (на Mac — в «Программах»):

```bash
npm run shortcut
```

### Расширение для Brave

1. Открой `brave://extensions` и включи **Режим разработчика**.
2. **Загрузить распакованное** → папка `extension/`.
3. В «Сведениях» включи **Разрешить в приватном режиме**.
4. После обновления Deepwork нажми ↻ на карточке расширения.

### macOS

Всё то же самое. Отличия: «Не беспокоить» включается через две команды в приложении «Команды» (`Deepwork Focus On` / `Deepwork Focus Off`, действие «Фокусирование»), для hosts macOS спросит пароль, программы блокируются по имени как в Dock. Mac-часть пока не проверялась на настоящем Маке.

### Установщик

`npm run dist:win` / `npm run dist:mac` собирают `.exe` / `.dmg` в `dist/` (electron-builder, без подписи).

## Как это устроено

```
main.js               окна, трей, IPC и связка всех частей
core/session.js       таймер-автомат: фазы, пауза, простой, выход с задержкой, восстановление после сбоя
core/enforcer.js      уровень → эффекты (DND, hosts, программы) и их откат
core/sys-win.js       Windows: DND (WNF + реестр), hosts через UAC, процессы и активное окно через PowerShell
core/sys-mac.js       macOS: DND через Shortcuts, hosts через пароль, процессы через lsappinfo
core/watchdog.js      сторожевой процесс для уровней 3–4
core/bridge.js        WebSocket для расширения (принимает только расширения)
core/scheduler.js     расписание и ритуалы      core/calendar.js   чтение .ics
core/telegram.js      бот (long polling)        core/phone.js      сервер для телефона (PIN, только локальная сеть)
core/datahome.js      папка данных, бэкапы      core/updates.js    обновления через git или релизы
renderer/             интерфейс (vanilla JS, Inter внутри), phone/ — приложение для телефона
extension/            расширение MV3: блокировка, лимиты, время на сайтах, чистка страниц
```

Данные: `%APPDATA%\Deepwork` (Windows), `~/Library/Application Support/Deepwork` (macOS), или выбранная папка.

## Для разработки

```bash
npm test                                       # unit и интеграционные тесты (node --test)
npm run check                                  # синтаксис всех скриптов
npm run dry                                    # тестовый режим: блокировки только в лог
node tools/demo-data.js ./demo-profile         # профиль с демо-данными
npx electron . --profile=./demo-profile --shot=shot.png --view=stats --extras
npx electron . --dry --port=47399              # вторая копия рядом с запущенной
```

GitHub Actions прогоняет проверку и тесты на Windows, macOS и Linux при каждом пуше.

## Ограничения

- Интерфейс только на русском; приложение для телефона и бот — тоже.
- iOS: настоящая блокировка на iPhone возможна только нативным приложением через Screen Time API (нужны Mac, Xcode и аккаунт разработчика). Пока на телефоне — веб-приложение и встроенный режим iOS «Фокус».
- Версии расширения для Firefox нет.
